# Geometric Representation Learning (`geom-repr`)

A modular library implementing training-free geometric methods on frozen pre-trained neural network representations:
* **SPM (Subspace Projection Method)** & **SPM-D (Discriminative SPM)**
* **MCM (Manifold Curvature Method)**
* **CSDM (Cross-Similarity Diffusion Matrix)** with Sinkhorn distance operators
* **Curvature-Leverage Prototype Pruning**
